# Resources

Evergreen material that isn't a dated learning entry: cheatsheets, command references, bookmark collections, reading notes, and snippets I reuse.

Unlike journal entries, these are **maintained** rather than dated — they get edited as my understanding improves.

Suggested layout as it grows:

```
Resources/
├── cheatsheets/     ← git, linux, sql, regex
├── snippets/        ← reusable code I keep forgetting
└── reading-notes/   ← notes on books, papers, talks
```

Prefer grouping by *how I'll look it up* rather than by source.

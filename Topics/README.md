# Topics

Reference hubs grouped by category. These are **not** copies of journal entries — each folder holds a short index that links back to entries in the date folders, plus any evergreen notes that aren't tied to a single day.

Why separate them from the date folders?

- The date folders answer *"what did I learn on 2026-11-06?"*
- The topic folders answer *"what do I know about transactions?"*

Duplicating files between the two would guarantee they drift apart. Links don't drift.

| Folder | Scope |
|---|---|
| [JavaScript](./JavaScript/) | Language semantics, the event loop, async, types, coercion |
| [NodeJS](./NodeJS/) | Runtime internals, streams, modules, the standard library |
| [Database](./Database/) | SQL/NoSQL, indexes, transactions, query planning, migrations |
| [Payment-Gateways](./Payment-Gateways/) | Gateway APIs, idempotency, webhooks, reconciliation, PCI scope |
| [System-Design](./System-Design/) | Scalability, caching, queues, consistency, failure modes |
| [DevOps](./DevOps/) | Linux, containers, CI/CD, observability, deployment |
